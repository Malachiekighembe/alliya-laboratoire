# Alliya Laboratoire

SaaS de gestion de laboratoire biomédical. Backend NestJS, frontend Next.js, base de données PostgreSQL (Supabase).

## Installation

```bash
# Backend
cd labo-backend && npm install

# Frontend
cd labo-web && npm install
```

## Exécution

```bash
# Backend
cd labo-backend && npm run start:dev

# Frontend
cd labo-web && npm run dev
```
